# RSA Digital Signature

## Description
This project demonstrates how to create and verify a digital signature using RSA in Java.

## Features
- Generate an RSA key pair.
- Create a digital signature using the private key.
- Verify the signature using the public key.
- Test verification after changing the original message.

## Technologies
- Java
- RSA
- SHA256withRSA
- NetBeans IDE
- Maven

## Execution Results
- Original message verification: true
- Verification after changing the message: false

## How to Run
1. Open the project in NetBeans.
2. Run the RSADigitalSignature class.
3. Check the Output window.
